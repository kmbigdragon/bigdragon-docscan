# docscan v0.1.0 — bản phát hành đầu tiên

docscan là thư viện quét tài liệu và thẻ kiểu CamScanner: **tự tìm viền tờ giấy/thẻ trong ảnh chụp → cắt và
nắn phối cảnh → áp bộ lọc scan**. Lõi viết bằng C++17 + OpenCV, biên dịch sang WebAssembly, nên **một gói npm
duy nhất chạy được ở cả trình duyệt lẫn Node.js**, không cần cài OpenCV hay build native.

## Điểm nổi bật

- **Phát hiện tự động**: trả về 4 góc của tài liệu kèm độ tin cậy, để UI hiển thị và cho người dùng kéo chỉnh.
- **Cắt và nắn phối cảnh**: hỗ trợ ép đúng tỉ lệ khổ giấy A4, Letter, thẻ căn cước/thẻ ngân hàng (ID-1).
- **4 bộ lọc scan**: giữ nguyên ảnh gốc, xám, đen trắng (xoá bóng đổ, tối ưu cho chữ), "magic color"
  (giấy trắng, mực đậm, giữ màu).
- **Chất lượng được đo trên dữ liệu chuẩn**: mean Jaccard index **0.869** trên bộ ICDAR 2015 SmartDoc
  (24 889 frame), đạt khoảng 0.97 với nền đơn giản. Chi tiết ở mục *Chất lượng*.
- **API TypeScript** có sẵn type; dữ liệu vào và ra là RGBA giống `ImageData`, nên không phải tự quản lý bộ nhớ wasm.

## Bắt đầu nhanh

**Trình duyệt** (ảnh lấy từ `<canvas>`):

```js
import { createDocScanner, AspectRatio } from 'docscan';

const scanner = await createDocScanner();               // tải docscan.wasm một lần
const photo = ctx.getImageData(0, 0, canvas.width, canvas.height);

const { found, confidence, corners } = scanner.detect(photo);  // 4 góc: TL, TR, BR, BL
const page = scanner.warp(photo, corners, { aspectRatio: AspectRatio.A4, maxOutputSize: 2000 });
const result = scanner.enhance(page, 'magic');          // 'none' | 'gray' | 'bw' | 'magic'

outCtx.putImageData(new ImageData(result.data, result.width, result.height), 0, 0);
```

**Node.js** (giải mã ảnh bằng `sharp`):

```js
import sharp from 'sharp';
import { createDocScanner } from 'docscan';

const { data, info } = await sharp('photo.jpg').rotate().ensureAlpha().raw().toBuffer({ resolveWithObject: true });
const scanner = await createDocScanner();
const { detection, image } = scanner.scan({ width: info.width, height: info.height, data }, { enhance: 'bw' });
await sharp(image.data, { raw: { width: image.width, height: image.height, channels: 4 } }).jpeg().toFile('scan.jpg');
```

**React**: xem mục *Dùng với React (Vite)* trong README, gồm hook tải module một lần và mẫu chạy trong Web Worker.

## API

| | Mô tả |
| --- | --- |
| `createDocScanner(options?)` | Tải và khởi tạo module. `options.locateFile` / `options.wasmBinary` dùng khi bundler hoặc CDN đặt `docscan.wasm` ở chỗ khác |
| `scanner.detect(image, { workingSize?, minAreaRatio? })` | `{ found, confidence, corners }`. Không tìm thấy thì `corners` là toàn khung ảnh |
| `scanner.warp(image, corners, { aspectRatio?, maxOutputSize? })` | Ảnh đã cắt và nắn phẳng; giữ hướng dọc/ngang của tứ giác |
| `scanner.enhance(image, mode)` | Áp bộ lọc scan |
| `scanner.scan(image, { detect?, warp?, enhance? })` | Gộp detect → warp → enhance trong một lần gọi |
| `scanner.version` | Phiên bản của lõi C++ (khớp với `package.json`) |
| `AspectRatio.A4` / `.LETTER` / `.ID_CARD` | Tỉ lệ cạnh dài / cạnh ngắn của các khổ phổ biến |

Ảnh vào là `{ width, height, data }` với `data` là `Uint8Array` hoặc `Uint8ClampedArray` RGBA; `ImageData` và
buffer RGBA của `sharp` dùng được trực tiếp. Dữ liệu sai sẽ ném `Error` kèm thông báo rõ ràng.
Lõi C++ (`core/include/docscan/`) cũng dùng được trực tiếp từ C++ với `cv::Mat`.

## Chất lượng

Đo bằng `docscan-bench` trên **ICDAR 2015 SmartDoc Challenge 1**, theo đúng giao thức Jaccard index của
cuộc thi (tính trên mặt phẳng tờ giấy). Trong ngoặc là khoảng tin cậy 95 % (bootstrap theo video).

| Nền | 1 | 2 | 3 | 4 | 5 | Tổng |
| --- | --- | --- | --- | --- | --- | --- |
| docscan v0.1.0 | 0.978 | 0.965 | 0.973 | 0.752 | 0.339 | **0.869** [0.841, 0.896] |

- Riêng tập test (19 870 frame, không dùng khi tinh chỉnh): **0.871** [0.839, 0.898]; 76.6 % số frame có JI ≥ 0.95.
- Với nền đơn giản (1–3), kết quả ngang các phương pháp cổ điển trong cuộc thi gốc. Nền 4 (giấy trắng trên bàn
  gần trắng) và nền 5 (bàn bừa bộn, vật đè lên giấy) còn yếu. Để so sánh, các mạng neural chuyên dụng đạt
  tổng điểm ≥ 0.98.
- `confidence` phân biệt tốt kết quả đúng và sai (AUROC 0.986), nên có thể dựa vào nó để quyết định khi nào
  yêu cầu người dùng chỉnh góc bằng tay.

Cách đo, bảng kết quả đã công bố để đối chiếu, và nhật ký thí nghiệm: `docs/EVALUATION.md`.

## Tương thích

- **Trình duyệt**: cần WebAssembly SIMD và Wasm exception handling, tức Chrome/Edge 95+, Firefox 100+,
  Safari 16.4+ (iOS 16.4+).
- **Node.js**: ≥ 18 theo `engines`; đã kiểm thử trên Node 24.
- **Bundler**: đã kiểm thử với Vite 8 + React 19 (dev, production build, Web Worker). Vite tự đóng gói
  `docscan.wasm`. Khi cài bằng đường dẫn thư mục (link), cần thêm `server.fs.allow` (xem README).
  Next.js chưa được kiểm thử.
- **Định dạng**: gói chỉ có ES module (`import`). Với CommonJS, dùng `await import('docscan')`.

## Hạn chế đã biết

- Tài liệu bị che một phần, hoặc nền rất bừa bộn, thường bị phát hiện sai.
- Góc được tìm trên ảnh thu nhỏ còn 640 px rồi phóng lên, nên với ảnh lớn sai số góc có thể vài pixel.
- Chưa nắn trang cong/gấp, chưa tự xoay theo hướng chữ, chưa có OCR.
- Tỉ lệ khung đầu ra lấy theo cạnh dài nhất của tứ giác, chưa ước lượng tỉ lệ thật từ phối cảnh; dùng
  `aspectRatio` khi biết trước khổ giấy.
- Bản WASM không giải mã JPEG/PNG (để module nhỏ gọn): trong trình duyệt dùng canvas, trong Node dùng `sharp`.

## Dành cho người phát triển

- Build từ mã nguồn: `npm run opencv:wasm` (một lần) rồi `npm run build && npm test`.
  Bản native (CLI, unit test C++, bench) dùng CMake preset `native`.
- Mỗi push và pull request đều qua CI: build native kèm 24 test C++, build WASM kèm 8 test JS, đóng gói và
  smoke test tarball. Bản phát hành này được build bằng đúng quy trình đó.
- Commit theo Conventional Commits, được kiểm tra bởi husky + commitlint. Quy trình phát hành: `docs/RELEASING.md`.

## Hướng phát triển tiếp theo

- Phát hiện bằng đường thẳng Hough/LSD và xếp hạng theo độ tương phản màu, nhằm cải thiện nền 4–5.
- Đo chất lượng cho thẻ trên bộ MIDV-500 / MIDV-2020.
- Tinh chỉnh góc ở độ phân giải gốc; ước lượng tỉ lệ thật từ phối cảnh.
